利用規約

最終更新日：2026-09-11

第1条（適用）

  1. 本規約は、【運営者名】（以下「運営者」）が提供するfrank html（以下「本サービス」）の 利用条件を定めるものです。
  2. 本サービスを利用したすべての方（以下「利用者」）は、本規約に同意したものとみなします。
  3. 本サービスは、アカウント登録をしていない方も作品の閲覧・プレイ・評価・コメントが可能です。 これらの行為を行った時点で、本規約に同意したものとみなします。

第2条（定義）

用語 意味
作品 利用者が本サービスに投稿したHTMLファイルおよびそれに付随する情報
投稿者 アカウント登録を行い、作品を投稿した利用者
閲覧者 作品の閲覧・プレイ・評価・コメントを行う利用者（登録の有無を問わない）
投稿ガイドライン 運営者が別途定める、作品の技術要件および内容要件

第3条（アカウント）

  1. 作品の投稿にはアカウント登録が必要です。閲覧・プレイ・評価・コメントに登録は不要です。
  2. 投稿者は、登録情報を正確に保ち、アカウントを第三者に利用させてはなりません。
  3. アカウントによる行為の結果は、当該アカウントの保有者に帰属します。
  4. 投稿者は、いつでもアカウントを削除できます。削除時、投稿した作品は非公開になります。

第4条（作品の権利）

  1. 作品の著作権その他一切の権利は、投稿者に留保されます。 運営者に移転しません。
  2. 投稿者は運営者に対し、本サービスの提供・維持・宣伝に必要な範囲で、 作品を複製・公衆送信・表示・翻案（サムネイル生成、一覧用の縮小表示、 紹介のための一部抜粋を含む）する、非独占的かつ無償の利用許諾を与えるものとします。
  3. 前項の許諾は、投稿者が作品を削除した時点で、技術的に可能な範囲で速やかに終了します。 ただし、削除前に生成されたキャッシュ、バックアップ、統計情報についてはこの限りではありません。
  4. 投稿者は、作品を他のプラットフォームで同時に公開することを制限されません。

第5条（投稿の条件）

投稿者は、投稿する作品について以下を保証するものとします。

  1. 自らが権利を有するか、正当な利用許諾を得ていること
  2. 第三者の著作権、商標権、肖像権、パブリシティ権、その他の権利を侵害しないこと
  3. 投稿ガイドラインに定める技術要件・内容要件を満たすこと

第6条（禁止事項）

利用者は、以下の行為をしてはなりません。

作品の内容について

  1. 第三者の権利を侵害する作品の投稿（無断転載、権利者の許諾のないキャラクター・ ロゴ・音源・画像の使用を含む）
  2. マルウェア、不正なコード、閲覧者の端末に意図しない負荷や損害を与えるコードの投稿
  3. 閲覧者を欺いて情報を入力させることを目的とする作品（本物のサービスを模したログイン画面、 決済画面、支援画面などを含む）の投稿
  4. 過度に暴力的・性的な内容、差別を助長する内容、自殺・自傷を誘引する内容の投稿
  5. 法令に違反する内容、犯罪を助長する内容の投稿

本サービスの運用について

  1. 本サービスの脆弱性を探索する行為、および第1号から第5号を回避しようとする行為
  2. 自動化された手段による評価・コメントの投稿、複数の識別子を使い分けた 評価の水増しその他の順位操作
  3. 他の利用者への誹謗中傷、いやがらせ、つきまとい、個人情報の無断公開
  4. 本サービスの運営を妨害する行為、過度な負荷をかける行為
  5. その他、運営者が不適切と判断する行為

第7条（評価およびコメント）

  1. 評価およびコメントは、アカウント登録の有無にかかわらず行うことができます。
  2. 評価の重みは、アカウント登録の有無にかかわらず一律です。 ただし運営者は、並び順の算出方法を予告なく変更することができます。
  3. コメントは事前審査を行わず、投稿された時点で公開されます。 ただし運営者は、自動的な判定により一部のコメントを公開保留とすることがあります。
  4. 投稿者は、自らの作品に付されたコメントを非表示にすることができます。
  5. 一定数の通報を受けたコメントは、運営者の確認が完了するまで自動的に非表示となります。
  6. 評価およびコメントの内容について、運営者は責任を負いません。

第8条（作品の削除・非公開）

  1. 投稿者は、いつでも自らの作品を編集・非公開・削除できます。
  2. 運営者は、以下の場合、投稿者への事前の通知なく作品を非公開または削除できます。
    • 第5条または第6条に違反すると運営者が判断した場合
    • 権利者から権利侵害の申立てを受けた場合
    • 法令または裁判所・行政機関の命令に基づく場合
    • 閲覧者の安全を確保するために緊急を要すると運営者が判断した場合
  3. 前項による措置について、運営者は理由を説明する義務を負いませんが、 可能な範囲で投稿者に通知するよう努めます。
  4. 投稿者は、第2項の措置に対し、【連絡先】宛に異議を申し立てることができます。

第9条（通報と発信者情報の取り扱い）

  1. 利用者は、権利を侵害する作品・コメント、その他本規約に違反する投稿について、 各ページの通報ボタンまたは【連絡先】から運営者に申し出ることができます。
  2. 権利侵害の申立ては、申立人の氏名・連絡先・侵害されたとする権利の内容・ 該当箇所を明示して行ってください。
  3. 運営者は、コメントの投稿にあたり、IPアドレス、ユーザーエージェントおよび 投稿日時を最長6か月間記録します。
  4. 前項の記録は、以下の場合にのみ参照・提供します。
    • 法令に基づく開示請求または裁判所の命令があった場合
    • 本サービスへの不正な攻撃の調査に必要な場合
  5. 記録の詳細な取り扱いは、別途定めるプライバシーポリシーによります。

第10条（サービスの変更・中断・終了）

  1. 運営者は、利用者への事前の通知なく、本サービスの内容を変更し、 または提供を中断・終了することができます。
  2. 本サービスを終了する場合、運営者は可能な限り事前に告知し、 投稿者が作品を回収するための期間を設けるよう努めます。
  3. 本サービスは無償で提供されており、稼働率について何らの保証もありません。

第11条（免責）

  1. 運営者は、投稿された作品の内容、動作、安全性について、いかなる保証も行いません。
  2. 作品は利用者自身の端末で実行されます。 作品の実行によって生じた損害について、 運営者は責任を負いません。
  3. 運営者は、利用者間または利用者と第三者との間に生じた紛争に関与しません。
  4. 運営者は、本サービスの利用により利用者に生じた損害について、 運営者の故意または重過失による場合を除き、責任を負いません。
  5. 前項にかかわらず、利用者が消費者契約法上の消費者に該当する場合、 運営者の責任を全面的に免責する趣旨ではありません。

第12条（規約の変更）

  1. 運営者は、必要と判断した場合、本規約を変更できます。
  2. 重要な変更を行う場合、施行日の7日前までに本サービス上で告知します。
  3. 告知後に本サービスを利用した場合、変更後の規約に同意したものとみなします。
