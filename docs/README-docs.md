# docs/ について

- frank-pro-handoff.md — 企画全体の引き継ぎまとめ。最初に読む
- security-design.md — セキュリティ設計の根拠と残存リスク
- terms-of-service-draft.md — 利用規約の叩き台（サイトには terms.html として公開版が別途ある）
- posting-guideline-draft.md — 投稿ガイドラインの叩き台（サイトには guidelines.html として公開版が別途ある）

terms.html / guidelines.html は、これらのmarkdownから「運営者向けメモ」節を除いて生成した。
文面を変えるときは、まずここのmarkdownを直してから web/*.html に反映すること。
